# 🛴 Urban Scooter | Proyecto Final QA Engineer
### Web Testing · Mobile Testing · API Testing
**Proyecto académico | Bootcamp QA Engineer – TripleTen**

## 📌 Descripción del proyecto

Urban Scooter es un servicio digital de alquiler de scooters eléctricos.

Como parte de mi proyecto final de QA Engineer, realicé actividades de análisis de requisitos, diseño y ejecución de pruebas para funcionalidades específicas de sus aplicaciones web y móvil, así como de su API REST.

El objetivo fue verificar el cumplimiento de los requisitos funcionales, identificar defectos y documentar los resultados de las pruebas.

## 🛠️ Herramientas utilizadas

- **Postman:** pruebas de API REST y validación de respuestas.
- **Jira:** documentación y seguimiento de defectos.
- **Android Studio:** ejecución de pruebas en un entorno Android.
- **Hojas de cálculo:** diseño y registro de casos de prueba, listas de comprobación y resultados.

## 🔎 Técnicas de testing

- Análisis de requisitos.
- Diseño de casos de prueba.
- Clases de equivalencia.
- Análisis de valores límite.
- Pruebas positivas y negativas.
- Pruebas funcionales.
- Documentación de defectos.

## 🧪 Áreas evaluadas

### 1. Aplicación web

Diseño y ejecución de pruebas para funcionalidades de pedidos y validación de campos, considerando los requisitos establecidos.

### 2. Aplicación móvil

Diseño y ejecución de casos de prueba para funcionalidades de la aplicación Android de repartidores, incluyendo escenarios de autenticación y gestión de pedidos.

### 3. API REST

Validación de solicitudes y respuestas relacionadas con la gestión de repartidores, incluyendo pruebas con datos válidos e inválidos.

## 📂 Evidencias técnicas

En este repositorio se incorporarán ejemplos de casos de prueba, listas de comprobación, pruebas de API y reportes de defectos.
