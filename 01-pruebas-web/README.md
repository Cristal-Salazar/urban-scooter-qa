# Pruebas web | Urban Scooter

Esta carpeta contiene las evidencias del análisis de requisitos, diseño y ejecución de pruebas funcionales de la aplicación web Urban Scooter.

Se incluirán listas de comprobación, validaciones de campos, resultados de pruebas y ejemplos de defectos identificados durante el proyecto final de QA Engineer de TripleTen.
