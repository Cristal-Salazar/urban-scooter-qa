# 📱 Pruebas móviles | Urban Scooter

**Proyecto:** Urban Scooter  
**Aplicación:** Android para repartidores  
**Tipo de pruebas:** Pruebas funcionales móviles  
**Herramienta:** Android Studio

## Objetivo

Verificar el funcionamiento de características específicas de la aplicación móvil de Urban Scooter, comprobando que su comportamiento corresponda con los requisitos establecidos.

## Funcionalidades evaluadas

Durante el proyecto final de QA Engineer de TripleTen trabajé con escenarios relacionados con:

- Inicio de sesión de repartidores.
- Validación de credenciales.
- Recuperación de contraseña.
- Aceptación de pedidos.
- Notificaciones relacionadas con pedidos.

## Entorno de pruebas

Se utilizó Android Studio para ejecutar la aplicación en un emulador Android.

**Versión de Android documentada:** Android 9.0.

## Actividades de QA

- Análisis de requisitos funcionales.
- Diseño de casos de prueba.
- Definición de precondiciones.
- Documentación de pasos de ejecución.
- Comparación de resultados esperados y reales.
- Registro de resultados y defectos identificados.

## Evidencias técnicas

En esta carpeta se incorporarán ejemplos de los casos de prueba móviles documentados durante el proyecto final.

## Aprendizajes

Esta actividad fortaleció mis habilidades para evaluar aplicaciones móviles, diseñar escenarios de prueba y documentar resultados de manera estructurada.
