# 🔌 Pruebas de API REST | Urban Scooter

**Proyecto:** Urban Scooter  
**Tipo de pruebas:** API Testing  
**Herramienta:** Postman  
**Proyecto académico:** Bootcamp QA Engineer – TripleTen

## Objetivo

Verificar el comportamiento de los endpoints de la API REST de Urban Scooter mediante solicitudes HTTP, comprobando que las respuestas y las validaciones de datos correspondan con los requisitos establecidos.

## Funcionalidades evaluadas

Durante el proyecto final trabajé con pruebas relacionadas con la gestión de repartidores, incluyendo:

- Creación de repartidores.
- Validación de datos enviados en solicitudes.
- Comprobación de campos obligatorios y opcionales.
- Pruebas con valores válidos e inválidos.
- Revisión de respuestas HTTP.
- Comprobaciones relacionadas con la eliminación de repartidores.

## Herramienta utilizada

**Postman:** herramienta utilizada para enviar solicitudes a la API y analizar las respuestas obtenidas.

## Técnicas de prueba

- Análisis de requisitos de API.
- Pruebas positivas y negativas.
- Clases de equivalencia.
- Análisis de valores límite.
- Validación de códigos de estado HTTP.
- Comparación de resultados esperados y reales.
- Identificación y documentación de defectos.

## Ejemplo de endpoint evaluado

**Método:** POST  
**Endpoint:** `/api/v1/courier`

**Funcionalidad:** creación de repartidores.

Las pruebas incluyeron la validación de solicitudes con diferentes datos de entrada y la revisión de las respuestas de la API.
