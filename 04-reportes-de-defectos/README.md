# Reportes de defectos | Urban Scooter

## Objetivo

Documentar los defectos identificados durante las pruebas funcionales del proyecto Urban Scooter, proporcionando información clara para facilitar su reproducción, análisis y seguimiento.

## Herramienta utilizada

**Jira:** registro y seguimiento de incidencias detectadas durante la ejecución de pruebas.

## Información de los reportes

Los reportes de defectos pueden incluir:

- Identificador de la incidencia.
- Título y descripción del problema.
- Precondiciones.
- Pasos para reproducir el defecto.
- Resultado esperado.
- Resultado real.
- Entorno de prueba.
- Severidad y prioridad, cuando estén documentadas.
- Evidencias disponibles.

## Evidencias

Se incorporarán ejemplos de defectos identificados durante las pruebas web, móviles y de API REST.

Los reportes se presentarán respetando la información registrada durante el proyecto final de TripleTen.
